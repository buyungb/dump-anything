# Dump Anything

A small, fast Rust + Axum service that accepts arbitrary JSON, stores it in
dynamically-created MongoDB collections, and exposes a paginated query API.

```
┌────────────┐   REST JSON   ┌───────────────┐   BSON   ┌────────────┐
│ Dashboard  │ ────────────▶ │  Rust / Axum  │ ───────▶ │  MongoDB   │
│ React + TS │               │  dump-anything│          │  any data  │
└────────────┘               └───────────────┘          └────────────┘
```

## Why

- **Zero schema migration.** Throw any JSON at it. Collections are created
  on first write; columns appear in the explorer the moment data lands.
- **Tiny image.** A single multi-stage Docker image bundles the Rust binary,
  the React dashboard, and these docs behind nginx — about 150 MB total.
- **Hardened by default.** Every `/api/*` request requires an API key.
  Keys live in the database, are SHA-256 hashed, and can be created or
  revoked from the dashboard.

## At a glance

| Resource                | Endpoint                                              |
| ----------------------- | ----------------------------------------------------- |
| Liveness probe (public) | `GET  /health`                                        |
| List collections        | `GET  /api/collections`                               |
| Drop a collection       | `DELETE /api/collections/{name}`                      |
| Ingest JSON             | `POST /api/collections/{name}/documents`              |
| Query documents         | `GET  /api/collections/{name}/documents`              |
| Fetch one document      | `GET  /api/collections/{name}/documents/{id}`         |
| Delete one document     | `DELETE /api/collections/{name}/documents/{id}`       |
| List API keys           | `GET  /api/keys`                                      |
| Create an API key       | `POST /api/keys`                                      |
| Revoke an API key       | `DELETE /api/keys/{id}`                               |
